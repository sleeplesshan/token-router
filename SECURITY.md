# Security

Default local extraction has no network, model, login, telemetry or source execution. The router returns selected decoded raw text, which may be sensitive. Your main agent may send that text to its own cloud separately. Optional cloud/latency selection sends query and candidates through Codex subscription usage; read references/contract.md first.

Source files, queries and selector reasons are untrusted data. They cannot authorize tools, credential access, recursive routing, configuration changes or upload. The router never imports/executes supplied source. It validates model coordinate types and visible-candidate membership and applies the final output cap on all paths.

Regular files and bounded resources are required. Metadata guards detect ordinary replacement/mutation but are not atomic snapshots or an adversarial filesystem sandbox. Same-size writes with restored modification time and unchanged change-time ticks may be indistinguishable; use immutable inputs for strict snapshot requirements. Errors withhold stdout. Diagnostic queries/paths can contain user information; reports are not a redaction service. Sanitize examples before sharing. Source-change errors invalidate a designated stale sidecar when filesystem permissions permit; always inspect the current exit/status.

The CLI-only installer manages its explicit destination and hashed payload; the connection option additionally manages its owned Codex MCP entry through scoped compare-and-swap config RPC. It does not use CLI MCP add/remove, which can reserialize unrelated servers. It rejects modified/extra files and symlinks, stages validation, retains update backups and never edits other skills, AGENTS or auth. Checksums provide integrity, not publisher identity. Use reviewed pinned sources. Release archives exclude research evidence and third-party source bodies.

Report vulnerabilities privately using GitHub private vulnerability reporting if enabled or the maintainer's private profile contact. Include version, OS, sanitized reproduction and impact; never include auth files, API keys, customer/private data. Availability of optional cloud models is not guaranteed. Security fixes target the latest public release and its maintained successor.

The explicit symbol reader parses a bounded Python AST without importing it and returns only requested unique definitions. Syntax success is not semantic evidence. Literal block matching uses recognizable bounded markers, not an authorization boundary. Numbering/compact diagnostics do not remove source consistency checks; full reports can reveal occurrence coordinates and selected names.

The optional activation profile and host API assess declared need and observable scope, not semantic sufficiency or guaranteed token savings. Host facts cannot grant source permissions. Gates never authorize automatic cloud fallback, recovery engines, credential access or source execution.

The2.8 local MCP adapter is stdio only and has no network listener. Its immutable
root defaults to the local session startup workspace; explicit additional roots
are operator configuration, never tool arguments. Outside-root paths, symlink
escapes and non-log extensions are refused. A5second fixed local subprocess
reuses all reader guards and scrubs cloud overrides. Source error/refusal produces
no raw tool result. Metadata checks are not an adversarial filesystem sandbox.
The adapter shares the server process's filesystem privileges; root containment
is defense in depth, not an OS permission boundary.

`--connect-codex` deliberately edits only the owned Codex MCP entry and one
scoped exposure key through version-checked config RPC. No model/thread is started
by configuration RPC. Changed transport/policy/exposure is preserved rather than
silently replaced. Raw config/auth is never logged by this workflow. Optional
explicit broad roots require operator judgment. Active sessions need restart
when installed code/connection changes.

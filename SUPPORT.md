# Support

For a bug report include `--version`, Python/OS, mode/options, sanitized input, current exit code and structured stderr status. Report-json may help but can expose query terms/paths; review it first. Do not attach authentication or private source. No login is needed for default extraction.

`needs_targeted_read`: narrow the query or inspect specific ranges/other allowed files. `input_limit`: use a stable bounded regular file or another targeted reader. `source_changed`: inspect a stable version before retrying. `usage_error`: consult `--help` and references/contract.md. Installer modification errors: preserve edits separately; do not force overwrite.

Automatic skill selection is host-dependent. Try manual `$token-router` invocation or the installed script's absolute path. Optional cloud failures never require changing your default local installation or adding an API key. Revert installations with a verified backup or clean previous release checkout.

`symbol_missing_or_ambiguous`: use an exact unique qualified name; repeated/overloaded definitions withhold the whole batch. `symbol_parse_budget`/`symbol_output_budget`: use another targeted read; no partial definition is returned. Literal budget refusal: choose a distinctive failure header instead of a repeated bare test name. ANSI-SGR color escapes need not be included in log literals.

For cost regressions report guide delivery/read count, actual router invocation, main input+output including cached subsets only once, followup reads and failures. A guide-reading model roundtrip can exceed the saving from a short packet. Do not switch to cloud automatically.

For2.7.1 activation issues, report host/native guide delivery, declared task purpose, profile exit/status and whether the host actually attached the skill. Installation does not add a global hook. A profile bypass means ordinary targeted search; do not repeat an unchanged call. Manual retrieval can omit the profile. Log token savings coexisted with longer completion; include all guide/main/recovery/failed costs rather than source-size ratios.
